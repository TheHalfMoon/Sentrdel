# R1 Contracts

Binding R1 contract documents in this directory:

- `cli-contract.md` — stable CLI envelope and exit semantics.
- `engine-security-pack-contract.md` — engine and Security Pack trust/capability boundary.
- `evidence-asel-contract.md` — canonical Evidence, Findings, Coverage, and ASEL authority/integrity contract.
- `context-learning-authority.md` — T095 authority ceiling for untrusted context, feedback, future Security Memory, and candidate-only Research/Learning behavior.

A contract describes authority and behavior that implementations must preserve. The presence of a contract does not imply that every future capability it constrains is implemented in R1.
