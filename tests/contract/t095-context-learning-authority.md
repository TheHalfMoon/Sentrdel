# T095 Context/Learning Authority Contract Checklist

This is a review-time contract fixture, not executable product behavior.

A future implementation claiming conformance must prove all applicable properties below with executable tests:

- [ ] repository/issue/CI/MCP/web/engine/model content cannot widen instruction authority;
- [ ] repository configuration cannot widen core permissions;
- [ ] feedback cannot mint FACT/OBSERVATION/VERIFIED or silently suppress Evidence;
- [ ] memory cannot mint authority, bypass the reconciler, or downgrade kernel DENY;
- [ ] stale/expired/unknown-provenance context fails closed;
- [ ] candidate-generation logic cannot read protected expected outputs;
- [ ] a candidate cannot modify/select evaluator, metric, holdout, kernel, reconciler, verification, or release authority for its current qualification;
- [ ] repeated protected qualification cannot become a tuning oracle;
- [ ] only the reconciler creates Findings;
- [ ] LLM/model-derived material remains INFERENCE/HYPOTHESIS only;
- [ ] unavailable memory/research/context infrastructure cannot be represented as positive security coverage;
- [ ] deferred Security Memory/Learning capabilities are not advertised as implemented by T095.
